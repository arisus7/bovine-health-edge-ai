# Sistema de Monitoreo de Salud Bovina con TinyML

## Descripción

Proyecto desarrollado durante un hackathon organizado por Syscom con el objetivo de monitorear la salud del ganado mediante el análisis de audio utilizando inteligencia artificial en dispositivos embebidos.

El sistema utiliza una Arduino Nicla Vision para capturar y procesar audio en tiempo real, identificando sonidos como tos y mugidos para generar alertas que pueden ser enviadas a un servidor.

## Tecnologías

* Python
* MicroPython
* Edge Impulse
* Arduino Nicla Vision
* TinyML
* Procesamiento de Audio

## Mi participación

* Desarrollo del firmware en MicroPython para la captura y procesamiento de audio.
* Implementación de lógica para el cálculo de niveles de intensidad sonora.
* Desarrollo de un programa en Python para recibir alertas y enviarlas a un servidor mediante peticiones HTTP.
* Apoyo en la integración del modelo de TinyML dentro del dispositivo.

## Lo que aprendí

* Desarrollo de sistemas IoT.
* Procesamiento de señales de audio.
* Implementación de modelos de Machine Learning en dispositivos embebidos.
* Comunicación entre hardware y servicios web.

## Contexto

Este proyecto fue realizado en equipo durante un hackathon de Syscom como una propuesta para apoyar el monitoreo de la salud bovina mediante tecnologías de inteligencia artificial e IoT.
